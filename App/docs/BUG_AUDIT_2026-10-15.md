## Still open

- An initially identical hidden copy of the inward register becomes divergent
  after a write to the visible register. Import accepts the initial copy, but
  later verification can reject the candidate workbook. Synchronizing copies
  requires preserving independent Excel relationships; archives are not ignored.
- A real worksheet rename can disconnect optional settings keyed to the old
  sheet name. Casing-only changes are handled above. Adopting another name's
  settings without stable sheet identity could attach another record's details.
  A deliberate identity migration is required.

Ambiguous continuation rows named Total that also contain quantity or per-piece
values still require review, because automatically treating them as either assets
or summaries could change the certificate weight. This is an unresolved data-policy
choice, not an additional patched finding. Unicode metadata chunking was an
unconfirmed hardening suggestion and is not counted.
